## 🌟 Overview

**Al-Haqq** ("The Ultimate Truth") delivers a profound digital journey through Quranic reflections, authentic Hadith narrations, and historical Islamic milestones. The application balances technical minimalism with rich aesthetics, utilizing glassmorphism overlays, custom typography (`Amiri`, `Cinzel`, `Inter`), and scroll-driven GSAP animations.

---

## ✨ Key Features

- **Immersive Visual Experience:** High-resolution dynamic background imagery curated from free, open-source cloud asset networks.
- **ScrollTrigger Animations:** Powered by GSAP for fluid, scroll-based section transitions and element reveals.
- **Responsive Navigation:** Interactive overlay menu with full support for mobile hamburger toggle navigation.
- **Quranic Linguistic Deep-Dives:** Focused comparative analyses (e.g., *Nafhah* vs. *Lafhah*).
- **Comprehensive Citation Index:** Complete list of primary Islamic academic sources and authentic Hadith references.

## 🚀 Installation & Setup

To run this project locally, simply clone the repository and open the primary `index.html` file in any modern web browser.

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/rayaantasnim/Islamic-Web.git
   cd Islamic-Web
   ```

2. **Run Locally:**
   - Open `index.html` directly in your browser, or
   - Use VS Code **Live Server** extension for real-time development reloading.
